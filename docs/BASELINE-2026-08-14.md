## Build Targets

The baseline CMake project declares:

- `attention_static`, the static library.
- `attention_shared`, the versioned shared library.
- `attention_tests`, the GoogleTest executable.
- `attention_benchmarks`, the benchmark executable.
- Optional strict performance registration through `ATTENTION_ENABLE_PERFORMANCE_TESTS=ON`.

The source tree contains the SMAO Phase 1 numerical kernel, public C and C++ headers, the transformer configuration foundation, tests, benchmarks, installation rules, and dependency helpers.

## Clean-Build Verification

The baseline was configured from an empty out-of-tree directory using:

```bash
cmake -S . -B /tmp/attention_stage0_clean_build \
  -DCMAKE_BUILD_TYPE=Release \
  -DATTENTION_ENABLE_NATIVE=ON \
  -DATTENTION_ENABLE_OPENMP=ON \
  -DATTENTION_ENABLE_CBLAS=OFF \
  -DATTENTION_ENABLE_PERFORMANCE_TESTS=OFF
cmake --build /tmp/attention_stage0_clean_build -j2
ctest --test-dir /tmp/attention_stage0_clean_build --output-on-failure
```

The configure completed successfully. The complete build reached 100 percent for the tested targets. The test suite completed with **38 of 38 tests passing**. No compiler warnings or errors were reported in the build log.

## Verified Test Coverage

The 38 tests cover exact decomposition, metric assembly, whitening, anisotropic distance, numerical guards, forward integration, algebraic equivalence, gradient comparison, C API behavior, and transformer configuration. The transformer configuration tests cover valid derived values, invalid dimensions, causal and precision restrictions, dropout validation, tied and untied output heads, and overflow behavior.

## Known Scope Limits

The following are intentionally recorded as incomplete rather than treated as failures of the baseline:

- The transformer computation graph is not implemented yet.
- Tokenization and vocabulary training are not implemented yet.
- Dataset ingestion, filtering, manifests, and leakage control are not implemented yet.
- Pretraining, fine-tuning, checkpoint recovery, and language evaluation are not implemented yet.
- F16 and BF16 computation are not implemented; the public numerical API rejects unsupported precision modes explicitly.
- A complete language-generation runtime is not implemented yet.
- Teacher-student, tools, memory, and external-context protocols are not implemented yet.
- Native performance targets are hardware-profile-specific; the portable fallback is validated for correctness but can be slower.

## Baseline Acceptance

Stage 0 baseline evidence is complete when this report, `Goal.md`, and `docs/ENGINEERING_CONVENTIONS.md` are committed together with the verified source state. Any future change that alters the build, public contract, architecture, performance, or supported scope must create a new baseline or update the relevant versioned record.
